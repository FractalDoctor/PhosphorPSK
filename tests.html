PhosphorPSK — Decoder Test Results

Accuracy testing of the PhosphorPSK BPSK decoder using the CLI test harness (PSKDecode). The CLI uses identical DSP code to the iOS app via symlinks — same source files, same binary logic.

These results are from synthetic signals generated by the harness. Over-the-air testing against real recordings is pending — the generator models a clean, hard-keyed BPSK transmitter with no fading or transmit pulse-shaping.

Methodology

  • All tests run via the PSKDecode CLI tool, which shares its DSP source files with the iOS app via symlinks (single source of truth).
  • Test signals are produced by the harness's own generator (PSKDecode gen): hard-keyed BPSK at 8 kHz with an idle preamble, an optional carrier offset, and optional additive white Gaussian noise at a target SNR.
  • Each signal is decoded and the output compared character-for-character against the known transmitted text.
  • Test message: CQ CQ DE PHOSPHORPSK. RNG seed: 1.

Decoder Settings

  • Sample rate: 8 kHz
  • Front end: complex NCO downconvert to baseband (I = s·cosφ, Q = -s·sinφ)
  • Matched filter: two cascaded biquad low-pass filters on I and Q, cutoff ≈ symbol rate
  • Timing: symbol-clock DPLL, nudged toward symbol centre on in-phase sign transitions
  • Bit decision: differential, sign of Re(z · conj(zprev)) — 1 = no reversal, 0 = 180°
  • Character assembly: canonical G3PLX Varicode, "00" inter-character delimiter
  • Carrier tracking: 512-point FFT, power-weighted centroid of the occupied band, smoothed

Varicode Table Verification

The Varicode table was checked independently: 128 unique codes, no code contains an internal "00", and an encode→decode round-trip of mixed text is exact.

Decoded exactly with additive noise at 0 dB wideband SNR. With 256 samples per symbol at 31.25 Bd, the matched filter provides roughly 24 dB of processing gain, so a 0 dB wideband signal is comfortably above threshold at the symbol level.

Notes

Acquisition Transient

When the carrier starts off-frequency, the decoder occasionally garbles or drops a single character while the FFT pulls the carrier onto the true centre and the demodulator settles. The message body then decodes cleanly. This is the only residual error in the synthetic set.

Suppressed-Carrier Acquisition

BPSK is a suppressed-carrier signal — during idle (continuous phase reversals) the energy sits in sidebands at the carrier ± half the symbol rate, so the strongest single FFT bin is offset from the true carrier. PhosphorPSK therefore estimates the carrier from the power-weighted centroid of the occupied band, which is symmetric about the true carrier, rather than from the raw peak. This is what lets the AFC acquire anywhere in the 700–2500 Hz passband.

Carrier Tracking

An internal squaring-loop AFC was evaluated and disabled: measuring the squared signal's absolute phase rather than its per-symbol change, it did not behave as a frequency discriminator and destabilised even a zero-offset carrier. Carrier tracking is handled entirely by the FFT centroid detector, which is stable and accurate on the synthetic set.

Summary

Against synthetic BPSK signals, the PhosphorPSK decoder demonstrates:

  • Clean signals: exact decode at BPSK31, BPSK63, and BPSK125.
  • Noise: exact decode down to 0 dB wideband SNR at an acquired carrier, thanks to the matched-filter processing gain.
  • Carrier acquisition: the AFC pulls in and decodes anywhere across the 700–2500 Hz audio passband, with at most a single-character transient during acquisition.
  • The core demodulator (complex downconvert + matched filter + differential BPSK + Varicode) is accurate. The remaining work is over-the-air validation and tightening the acquisition transient.
